# Desk vent case (OpenSCAD)

One-piece open skirt + tilted roof. Panel **screws to the roof underside** (window + M3 holes only — no pocket). Spec: `../wscase_checkpoint.md`.

## Preview

Open `wscase.scad` in OpenSCAD → **F5**.

## Export

| `part` | Use |
|--------|-----|
| `fit_check` | Flat 1:1 panel — open beside Exterior-Size.jpg; measure **yellow PCB edge → hole** (4 mm) |
| `hole_gauge` | Print first — drop panel on it, check M3 alignment |
| `case` | Full skirt + roof → **F6** → STL |

Set in Customizer → **F6** → Export STL.
